# README 图片来源

面板图片来自独立演示机上的 Meridian v1.13.0，通过浏览器访问公开只读演示站采集。数据库为新建实例，站点、流量与日志全部使用示例数据，没有复制用户数据库。

截图中的域名统一替换为 `example.com` 下的保留示例域名，客户端地址使用文档保留网段 `192.0.2.0/24`。不包含真实媒体源、账户、Bot Token 或私钥。图片导出时不保留元数据。

`telegram-bot.html` 是 Telegram 操作示意图的可编辑来源，按 1440 × 1000 视口渲染；其菜单、站点摘要与确认提示对应当前 Bot 实现，并在画面中标注模拟内容。

README 使用 WebP 图片；主图和桌面页面保持清晰可放大，手机页面组合展示。更新时应先验证演示站只读限制，再截图；不要从私人实例采集公开素材。
