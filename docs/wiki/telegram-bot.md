# Telegram Bot

Bot 提供管理员私聊操作与独立的定时日报。两者共享 Token，但开关、权限和接收目标相互独立。

![Telegram 管理设置，示例数据](https://raw.githubusercontent.com/snnabb/Meridian/v1.13.0/docs/images/telegram-settings.webp)

## 配置管理功能

1. 向 [@BotFather](https://t.me/BotFather) 创建 Bot，取得 Token。
2. 打开“全局设置 → Telegram Bot”，填写 Token。
3. 在管理员 ID 中填写正整数 Telegram **用户 ID**，多个用逗号分隔，最多 10 个。
4. 填写真实面板外部地址，例如 `https://panel.example.com:8443`。
5. 打开 Bot 管理开关并保存，然后向 Bot **私聊**发送 `/start`。

面板外部地址不能包含基础路径、查询参数、账号信息或片段。它用于生成站点入口，应包含浏览器实际使用的非默认端口，不填写反向代理的内部监听端口。

管理员 ID 不是 Telegram 用户名，也不是群组 Chat ID。可用 Bot 的 `/id` 查看自己的 ID。

Token 加密保存；再次打开设置时不显示原文，留空可保留已有 Token。正式部署要有持久的 `JWT_SECRET` 与独立 `MERIDIAN_SECRET_KEY`。

## 命令与按钮

| 命令 | 用途 |
| --- | --- |
| `/start` | 打开新的管理菜单。 |
| `/menu` | 返回当前面板主菜单。 |
| `/sites` | 管理站点。 |
| `/accounts` | 管理站点账号与到期提醒。 |
| `/import` | 上传或粘贴 JSON/CSV，预览后导入；也可解析开号信息。 |
| `/export` | 选择格式和账号字段，接收 JSON/CSV/TXT 文件。 |
| `/add` | 分步添加站点。 |
| `/address` | 查看站点访问地址。 |
| `/traffic` | 查看流量。 |
| `/report` | 获取即时日报。 |
| `/status` | 查看运行概览。 |

## 添加与编辑站点

私聊菜单可添加站点，或编辑名称、主地址、入口、播放模式、配额、限速、缓存、备用线路和客户端标识，也可启停、删除与检测连接。

填写流程按步骤进行。输入后会更新当前操作消息；切换菜单与返回通常复用原消息，不持续发送新菜单。

提交修改前显示确认摘要。确认按钮有效期为 10 分钟，只能执行一次。如果其他管理员或面板已经修改配置，旧确认不能覆盖新的配置，需要重新选择并确认。

## 账号、导入与文件导出

v1.14.0 起支持以下命令：

| 命令 | 用途 |
| --- | --- |
| `/accounts` | 查看、添加、编辑或删除站点账号；直接显示保存的密码，可设置提前提醒天数。 |
| `/import` | 上传 JSON/CSV 文件或粘贴内容，先预览再选择新增、更新或跳过；也可选择解析开号信息。 |
| `/export` | 选择格式、是否包含账号及密码，接收 `.json`、`.csv` 或 `.txt` 文件。 |

`/add` 或 `/import` 中选择粘贴开号信息后，先进入账号草稿。可直接修改账号、密码、到期时间、提前提醒和备注，点击“继续，检查站点”后再核对站点名称、入口和地址。确认页仍可返回修改账号；只有点击“保存并启用”才会写入站点和账号，取消或草稿过期不会保存。自动识别的播放方式默认“自动发现”；服务器未配置自动发现密钥时显示手动回源并提示原因。名称、入口模式、路径/域名/端口和播放模式仍可修改，账号和备用线路随草稿保留。

导出支持无账号站点，不会把文件内容拆成聊天消息。TXT 采用可直接阅读的站点与账号分组，包含到期提醒说明；原线路、备用线路和反代线路分别标注，同一站点的线路不会因多个账号重复输出。TXT 支持原线路、反代线路、多线路；CSV/JSON 文件可以直接发给 Bot，再查看导入预览。新导入的站点默认停用，更新已有站点保留启停状态和文件中未提供的密码。重复项可批量或逐项处理。

账号提前提醒与日报独立：设置到期日期和提前天数后，只在到达提醒时间时推送一次。`0` 表示到期时，选择“关闭提醒”可停用。提醒发给当前配置的 Bot 管理员；同一到期日期和提前天数组合在重启后不会重复发送。提醒消息带“已处理”“忽略本次”和“明天再提醒”按钮，面板会保留每次成功或失败的发送记录及失败原因；账号续期会记录原到期日、新到期日和续期天数，账号列表可选择一月（30 天）、一季度（90 天）、一年（365 天）或自定义 1–3650 天续期；站点列表的 `👤数量` 表示已保存的账号数。

在 Telegram 中发送或粘贴地址时，Telegram 可能抓取链接预览。请求日志中的 `TelegramBot (like TwitterBot)` 若仅访问 `/`、`/web/index.html`，通常是读取页面，不代表账号登录或播放。账号备忘录不会自动向 Emby 发送账号密码；Bot 返回消息已关闭链接预览，但用户发送消息时的预览仍由 Telegram 客户端决定。此类请求仍可能到达上游，是否被限制取决于服务商的全站 UA / IP 规则。

## 定时日报

填写“接收 Chat ID”，选择每天或每周、发送日和发送时间。时间按 [全局时区](traffic-and-quota.md) 解释。

- 可以向个人、群组或频道发送日报；Bot 必须具备发送权限。
- 只启用日报，不会自动启用私聊管理。
- 接收日报的群组或个人不会自动成为管理员。
- “立即发送日报”用于验证 Token、Chat ID 与发送权限。

管理员与日报接收人的区别：

| 配置 | 用途 |
| --- | --- |
| 管理员用户 ID | 允许指定用户在私聊中管理 Meridian。 |
| 接收 Chat ID | 指定定时日报投递目标，不授予管理权限。 |

## 连接方式

Bot 使用长轮询，无需开放 Webhook 端口。同一个 Token 只能交给一个接收程序；不要同时运行其他长轮询 Bot 程序或遗留 Webhook 接收配置。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| `/start` 没有管理菜单 | 管理开关、保存状态、管理员用户 ID、是否私聊。 |
| 能收到日报却不能管理 | 日报 Chat ID 不代表管理权限，单独配置管理员用户 ID。 |
| Token 留空后无法开启 | 尚未保存过有效 Token，先填写并保存。 |
| 连接显示冲突 | 是否有另一个接收程序使用同一 Token，或上游 Webhook 尚在使用。 |
| 地址端口错误 | “面板外部地址”是否保留真实非默认公开端口。 |
| 日报时间不对 | 全局时区、每天 / 每周频率、发送日与时间。 |
| 按钮过期或提示配置变化 | 重新打开菜单，检查最新配置并重新确认。 |

不要公开 Token、管理员真实 ID 或包含播放凭据的消息。泄露 Token 后到 BotFather 撤销并更新配置。
